Frontend Dashboard Notification is an add-on for Frontend Dashboard WordPress plugin which allows user to show notification in Frontend Dashboard page. There are six notification slots where users can show content, image, slider, post or gutenberg blocks. The six notification slots can be restricted to users by their user role or dashboard menu or notification slot.

Frontend Dashboard Notification is an add-on for Frontend Dashboard WordPress plugin which allows user to show notification in Frontend Dashboard page. There are six notification slots where users can show content, image, slider, post or gutenberg blocks. The six notification slots can be restricted to users by their user role or dashboard menu or notification slot.


== Installation ==
1. Upload the "frontend-dashboard-notification" directory to the plugins directory.
2. Go to the plugins setting page and activate “Frontend Dashboard Notification”
3. Go to WP Admin | Notifications and add new notification.
4. Do save.
